# AWS MSP AI Hackathon（devpost-aws-msp-ai-2026）— meta

## 概况（除标注外均为 2026-11-25 详情页直抓，原件见信源[1]）

- **赛题本体**：为 AWS 托管服务提供商（MSP）生态构建"AI-first"解决方案——Track 1 打 MSP 内部运营（自动化运维/交付效率），Track 2 打面向客户的 AI 服务产品化。强制实质使用至少一项 AWS AI 服务，方案须已公开部署且 production-ready（架构图 + HLD 作证明），非 demo 级。
- **奖项结构**：$64,000 全现金——双赛道各 1/2/3 名（$10k/$7k/$5k，合计 $44k）+ 按产品线分设的 10 个特别奖（各 $2k，合计 $20k）。特别奖按 Bedrock AgentCore / Bedrock App / Quick App / Strands SDK / Frontier Agents 五条产品线各赛道分评——技术选型直接对应奖金入口。
- **资格硬门槛（关键差异点）**：参赛**组织**须为 AWS MSP partner 或 AWS Partner Network（APN）成员；个人须达所在国法定成年。这不是纯公开赛——个人开发者无 APN 资质则只能挂靠合规组织参赛，参战前必须先核资格。
- **附加回报**：获奖方案进入 AWS Use Case Library、获 GTM 支持考量与 Marketplace 上架赋能——对 toB 方案是奖金外的分发渠道。
- **热度（列表卡口径）**：2026-11-25 为 541 参与者、17 天倒计时；本窗口（11-19→11-25 快照间）新上榜。
- **AI/LLM 条款**：未设 AI 辅助开发限制；AI 使用是赛题本体（见 ai_policy）。

## 参与状态与窗口（2026-11-25 核对）

- 提交窗口内：截止 2026-12-11 12:00pm PST，距快照日 17 天（列表卡 '17 days left' 互证）。窗口短，且提交物要求已部署 URL + 私有仓库 + YouTube 演示 + HLD——从零起步难以在窗口内达标，适合存量 AWS 方案"显著更新"参赛。
- 与本库关联：本条目为 devpost 线首个"toB 基础设施/云厂商生态绑定"象限（此前 devpost 条目均为 toC 应用/游戏/生产力向）；若库内作品线未来做 agent 基础设施，Bedrock AgentCore/Strands/Frontier Agents 的特别奖设置是 AWS agent 技术栈的风向标信号。
