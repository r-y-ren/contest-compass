# Cloud9 x JetBrains: Sky's The Limit Hackathon 2026（devpost-cloud9-jetbrains-2026）— meta

## 概况（除标注外均为 2026-11-25 详情页直抓，原件见信源[1]）

- **赛题本体**：电竞数据×AI 工具链应用——用 JetBrains 工具链（含 AI agent IDE JetBrains Air 与 Junie）构建三类别应用：VALORANT/GC 选手侦察与道具点位、LoL 宏观侦察与 Fearless Draft BP 管理、展位 mini game。GRID 官方电竞数据接口可选接入。
- **奖项结构**：$25,000 池（列表卡口径）——三类别 Best 各 $6,000 现金 + GDC 门票与差旅（对电竞/游戏方向含曝光价值），Runner-up 各 $2,000；另设 AI 工作流叙事 bonus $1,000。详情页分项合计 $25,300（$25,000 主池 + $1,000 bonus）——两口径差异见缺口清单。
- **AI/LLM 条款**：AI 使用被官方鼓励（编码 agent Junie/Codex/Claude 点名推广），且设专项 bonus 奖励 AI 工作流叙事——本库 devpost 条目中首个"AI 辅助开发本身被计入评审价值"的赛。
- **热度（列表卡口径）**：2026-11-25 为 1,148 参与者、约 2 个月窗口；本窗口新上榜（11-19 快照无此卡）。
- **参与门槛**：须实际使用 JetBrains 工具链（.idea/.junie/.air 目录留痕作证据）；电竞类别需要懂 VALORANT/LoL 战术语境或用 GRID 数据；mini game 类别有 Riot IP 合规硬约束（原创素材）。

## 参与状态与窗口（2026-11-25 核对）
