# Meta VR Start Developer Competition 2026（devpost-meta-vr-start-2026）— meta

## 概况（除标注外均为 2026-10-11 官方直抓）

- Meta 第二届 VR Start 开发者大赛（首页官方回顾 2025 届："over 2,900 developers joined the competition and delivered more than 650 submissions"），面向 **Horizon OS 生态**的 VR 体验；三赛道（Entertainment/Gaming/Productivity）× 双 Division（New Experience / Adapted-Significantly Updated），特殊奖六席 + Judge's Choice 两席。
- **$1,000,000 奖金池精确自洽**（rules §6 奖金表逐项加总 = $1,000,000：Track 810k + Special 150k + Judge's Choice 40k）。
- **两阶段评审**（rules §7）：Stage One pass/fail 可行性筛选（feasibility/originality/overall quality）→ Stage Two 四项**等权 25%**：Innovation & Creativity / Experience Design / Technical Implementation / Polish & Presentation。
- **资格硬门槛**：18+；**巴西、魁北克居民不可参赛**（rules §3 原文点名）；须 Meta 账号 + Developer Access；**提交时须已是 Meta VR Start Program 会员**（首页直给 program 入口）；作品原创、未获 Meta 直接资助、只用公开/Start 会员工具；每参赛者/组织一次提交；团队为非正式组合（2+ 人，一名 Team Representative 提交），Organizations 可参赛。
- 热度（列表卡口径，2026-10-11）：2866 participants、窗口过半（"about 1 month left"）。
- 设计三原则（rules §5，与 VR Start 计划的产品导向一致）：airplane seat test（狭小空间可玩）、one bus stop test（短会话友好）、take it away test（摘掉头显就不成立才算 VR 原生）。

## 参与状态与窗口（2026-10-11 核对）

- 提交截止 **2026-11-18 12:00 PM PT**，距今约 5 周；放榜 2026-12-11 前后。当前处于提交窗口内，status: active。
