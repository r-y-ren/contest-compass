## 一、评审偏好（从章程/评委讲评/获奖名单可观察到的取向）

- **一手（官网《全场大奖评审规则》2026-09-18，取代新浪单源）**：全场大奖=六冠军跨赛道评审，三组 12 专家、六维加权——技术创新组 35%（创新性/技术·研究深度）+成果可信与开放生态组 25%（完成度与可验证性/开源价值与复用）+场景价值组 40%（问题价值与实际影响/场景落地与生态协同潜力·新增）；**证据优先**：仅有概念描述、未来计划或无法核验的口头主张不按已实现成果计分；路演 10 分钟（陈述5+Demo3+提问2），材料赛前锁定，现场公证。
- **一手（官网赛道简介）**：各赛道分阶段差异化权重——新智基座五维 25/25/25/20/5（场景可复制性/多Agent协同/Skill工程体系/工程落地与安全审计/开源贡献）；前沿探索算法赛题 45/30/20/5（技术性能/科学意义/方法创新性/开源贡献）；开放探索赛题 45/30/20/5（**问题定义与环境设计质量占 45%**/探索过程与信号/可检查性与可延续性/开源贡献）；无界应用六维"真问题、真场景、真闭环"导向。
- **一手（官网简介原文）**：初赛作品三要件——"具备开源价值、可运行 Demo 和真实应用潜力"；**2026-09-11 官网声明升级口径：鼓励开源但不强制开源**——开源与否/范围/许可证由团队自主决定，闭源项目一视同仁；开源贡献是评审重要组成而非唯一标准。
- **一手（官网流程注）**：前沿探索/具身未来按赛题独立比拼、独立评分排名、均分赛道奖池（每赛题冠军 25 万）——同赛道内不同赛题不直接互斥竞争。
- **获奖实证（首届全场大奖，媒体多源）**：ExpLoop Lab《MirrorPeptidizer》镜像多肽 De Novo 计算设计——真实科学问题+计算方法+**湿实验验证**，与"证据优先"规则自洽；六冠军中科研类（多肽设计/时空感知算法）占 2 席，企业场景类（数据治理/商业航天/双臂协作/园区巡逻）占 4 席。
- 结构性观察（一手奖金表反推）：奖金梯度（全场 100 万 > 赛道冠军 25~50 万）与成长支持 10 项表明主办方取向是"开源落地 + 孵化通道"而非单纯竞技。

## 三、往届差异化点（什么样的作品拿到了最高奖）

- **首届全场大奖（唯一实证点，媒体多源）**：ExpLoop Lab《MirrorPeptidizer：De Novo 镜像多肽设计算法》（前沿探索·开放探索赛题冠军）——科研计算设计类项目，决定性差异信号是**湿实验验证**（来源 InfoQ/中新社/杭州网多源一致）：在"证据优先"评审规则（官网一手）下，唯一可核验的"真做出来了"证据。
- 最高奖路径（官方一手确认）：先夺六竞赛单元冠军之一（赛题内独立评分）→ 9/23 "冠军 Showtime" 10 分钟路演（陈述5+Demo3+提问2）按公式评分——"答辩与 Demo 展示能力"是顶层奖项的显性门槛（原新浪单源口径已获官网《全场大奖评审规则》证实并细化）。
- 开源贡献为各组评审显性维度（全场大奖组 25% 权重、各赛道 5~20%）：GitHub 活跃度、社区协作证据链在评审中可量化对表；但开源**不强制**（官网 09-11 声明）——不开源的项目靠可复现材料补"可检查性"。
- 部分赛道赛题独立比拼（前沿探索/具身未来每赛题独立冠亚季、奖池减半至 25/15/5 万）：选赛题即选竞争池，冷门赛题的席位竞争密度可能更低（推断，标注为推断）。

## 四、反面观察（常见失分模式，若有依据）

- **一手红线（官网《全场大奖评审规则》）**：证据优先——"仅有概念描述、未来计划或无法核验的口头主张，不按照已实现的成果计分"；复赛/决赛评审重点"项目是否解决真实问题，核心链路能否完整运行，关键能力能否独立验证"（官网复赛启动稿一手）——无验证闭环的 Demo 叙事是显性失分模式。
- **一手红线（同规则）**：程序性申诉不受理"单纯认为评分过低/对评委专业判断异议"——专业判断差异属评审正常组成；材料赛前锁定后不得因观摩或提问实质性修改。
- **一手红线（官网简介）**：Token/算力补助以"完成初赛作品提交并通过作品有效性审核"为前提；第三方依赖/模型权重许可不洁会在基金会法务与 IP 合规审查环节暴露；前沿探索赛道允许商业 API/闭源模型但须披露调用环节与可复现性影响（官网一手）。
- 评委讲评/失分案例：**不存在**（首届刚闭幕，官网未发布复盘材料）——除上述规则层红线外无可证失分模式条目，如实留空。

## 五、赛点检查表（评审标准 → 可执行检查项）

- [ ] 全场大奖六维自证（官网一手权重）：问题价值与实际影响 / 创新性 / 技术·研究深度 / 完成度与可验证性 / 开源价值与复用 / 场景落地与生态协同潜力——每维一段可陈述证据
- [ ] "证据优先"自检（官网一手）：每项关键主张对应可核验证据（Demo 运行记录/代码/实验或实机结果/日志）；剔除一切"概念描述+未来计划"式表述
- [ ] 赛道权重对表（官网一手）：按所选题道逐项加权自评——如开放探索赛题"问题定义与环境设计质量 45%"要求问题包/探索环境/发现信号预定义先行
- [ ] 开源策略决策：开源非强制（官网 09-11 声明）——若开源，准备仓库活跃度与社区协作证据链；若不开源，以可复现材料（环境配置/部署说明/运行日志）补"可检查性与可延续性"
- [ ] 官网三要件自证：开源价值 + 可运行 Demo + 真实应用潜力各一段可陈述（官网原文）
- [ ] IP 合规自检：第三方依赖许可、模型权重开源兼容性、商业 API 调用披露（对应基金会法务审查环节）
- [ ] 若晋级单元冠军：按《全场大奖评审规则》备路演包——10 分钟（陈述5+Demo3+提问2）+ 1 页"场景落地与生态协同"增补页 + 材料赛前锁定纪律

## 六、对本框架的启示（喂给 K-02 / 验收报告）

- 方向契合：AI 工具全放行 + 开源不强制 + 商业 API 可用（须披露）——本框架"AI 辅助原创 + 开源合规"产出栈与赛事兼容，合规成本近零；且"证据链/可复现"导向与框架的 verify 习惯天然对齐。
- 首届实证信号：全场大奖给了"科学问题+计算方法+湿实验验证"——我方无湿实验室资源时，对标路径是"公开数据集第三方基线对比+可复现环境"满足验证充分性（中等成本，winners/2026.md 可迁移性节）。
- 竞争结构：两赛道按赛题独立评奖（每赛题独立冠亚季）——选冷门赛题降低席位竞争密度（推断）；企业场景类冠军 4/6 席表明"真实场景闭环"类作品在 GOAI 走量。
- 一鱼多吃复盘：原决赛窗口（09-22/23）与 lablab.ai 语音赛（09-30 截止）双投设想已随首届闭幕失效；GOAI 2027 已发布展望视频《智启新程》（单源），下届 watch 记入 meta 待办。
- 刷新触发：官网获奖公告 + 作品页/代码仓库发布（meta 待办 1/2）→ winners 深构回填 → 本文件方法论分布层与频次表回填；K-02 引用时冠军层按中置信（媒体多源）、深构层按零值处理。
