## 一、评审偏好（从章程/评委讲评/获奖名单可观察到的取向）

- **一手（评审机制原文）**：初赛结果仅用于筛选入围决赛团队，**不与决赛成绩累加**；决赛奖项以**线下真机评测结果**和官方评审结果为准——最终裁决在真机现场表现，仿真榜单分数只是入场券。
- **一手（合规红线反推）**：明文禁止伪造评测结果（人工遥控、剪辑伪造、硬编码演示）、刷分——评审高度警惕"演示造假"；决赛现场基于主办方平台真机部署，使伪造在物理上不可行。

## 三、往届差异化点（什么样的作品拿到了最高奖）

- **无往届**（首届）。可证的仅结构性差异，均为章程反推非实证：
  - 漏斗结构：线上仿真初赛（1360 队报名，2026-10-07 抓取时点）→ 公示入围 → 线下真机马拉松三天定奖——真机调优与部署能力（而非纯离线刷榜）决定最终座次。
  - 统一基座赛制：全员同起点（LingBot-VLA 2.0 开源权重 + 同一仿真评测体系）——差异化空间被压缩到后训练配方（数据配比/优化器/任务泛化），"从零造模型"不适用。
  - 官方基线锚点：发布权重 RoboTwin Clean 93.52% / Randomized 92.80%（仓库 README）——参赛方案须以此为参照系证明增量。

## 四、反面观察（常见失分模式，若有依据）

- **章程明文红线（一手）**：伪造评测结果（人工遥控/剪辑伪造/硬编码演示）、刷分、破坏平台——直接取消资格类。
- **数据越界（一手）**：使用 randomized 数据训练初赛任务——违规于指定 clean 数据边界。
- **结构性风险（章程反推）**：只优化仿真榜单、不练真机部署——初赛分数不入决赛总成绩，入场后"零真机适应"在三天马拉松内难补救；反之入围名额有限，初赛投入不足连入场券都没有——两段能力都不可偏废。

## 五、赛点检查表（评审标准 → 可执行检查项；快循环验收清单的派生源）

- [ ] 基座合规：模型起点 = 官方 LingBot-VLA 2.0 权重（Apache-2.0），训练数据 = 指定 RoboTwin 2.0 clean 子集（无 randomized 混入）。
- [ ] 评测可复现：评测结果有 log 级证据链，无人工遥控/剪辑/硬编码成分（红线自查）。
- [ ] 双段能力：仿真榜单成绩（入场券）+ 真机部署预案（三天马拉松内可执行的调优/部署 SOP）。
- [ ] 增量对照：相对官方基线（Clean 93.52%/Randomized 92.80%）的明确增量度量。
- [ ] 现场约束：入围队可赴上海 2026-11-13~15（主办方提供真机/数据/算力/交通住宿）——人工到场可行性预判。
- [ ] 社区面（可选加分）：开源贡献与创意 Demo 材料同步小红书征集渠道。

## 六、对本框架的启示（喂给 K-02 / 验收报告）

- **门槛画像**：编程/黑客松型、开源基座微调赛——无机械臂硬件门槛（初赛纯仿真；决赛真机由主办方提供），实际门槛为 GPU 算力（6.4B VLA 后训练）与决赛现场出席；与 ACG/多模态生成栈的技术重叠度低，与 RL/机器人训练栈重叠度高——框架契合度判断需谨慎。
