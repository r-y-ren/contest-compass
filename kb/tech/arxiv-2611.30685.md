# 轻量长期时序预测综述：小模型为什么 work，以及参数量被虚报了多少

> 来源：https://arxiv.org/abs/2611.30685 （2026-11-23，摘要经 arXiv API 实抓 2026-11-25）。GitHub search 论文标题短语无官方仓（2026-11-25 实查）。本卡内容出自本次抓取的摘要，未读 PDF 全文。

## 是什么

一篇**综述 + 代码级审计**双体裁的论文（作者 Issam Ait Yahia 等）：对约 **35 个轻量长期预测模型做 6 族分类**，统一记号并给每个核心模型画架构图；提出**结构化线性视角**——最小的模型是"受频率截断或周期折叠约束的线性映射"，并在 **8 个基准上对每种约束做闭式检验**；综述之外附**16 个官方代码仓的审计**：逐仓复现论文自报参数量，**发现最高 289 倍的报告差距**；最后给出模型选择与参数量报告的实操指南和开放问题。定位是补现有综述"按骨干分类、把效率当边角话题"的空档。

## 解决什么问题

长期预测界两极分化：一方把 Transformer/TSFM 推到数亿参数，另一方证明数百~数万参数的小模型在标准基准上仍有竞争力——但**"小模型为什么 work"没人系统回答**，且**参数量的报告口径无人核查**。做对比实验的人因此面临两个坑：不知道该选哪个小模型当基线；以为自己在比较 100K 参数模型，实际比较的可能差两个数量级。

## 相比前方法优势

- **首个把"效率"当主线的轻量预测综述**：既有综述按骨干组织、效率只是附带话题；
- **机理解释而非榜单罗列**：结构化线性视角把小模型的竞争力归因到"频率截断/周期折叠约束的线性映射"，并在 8 基准闭式检验——可证伪、可迁移；
- **代码级审计是稀缺品**：16 官方仓逐个复现参数量、暴露最高 289 倍虚报——这是所有依赖论文自报参数量做比较的后续工作的纠偏依据；
- **给出可操作产出**：模型选择与报告的实操建议（不是只停在 taxonomy）。

## 局限（如实标注）

- 无官方代码仓（GitHub search 2026-11-25 实查 0 结果），闭式检验与审计脚本暂不可直接复用，只能按摘要口径参考结论；
- 审计覆盖 16 仓、检验覆盖 8 基准，覆盖面有限（综述自称约 35 模型）；
- "结构化线性视角"的闭式检验以摘要口径为准，各约束在非标准基准/真实业务数据上是否仍成立未知；
- arXiv 预印本，未经同行评审；289 倍虚报的点名情况需读全文核对（本卡未读 PDF，不引具体仓名）。

## 如何用于比赛（比赛映射展开）

- **数模-预测与评估**（reuse_cost 低）：三层用法——(1) 选型表：按 6 族直接挑 2-3 个轻量模型当基线，避开"上大模型"的资源陷阱；(2) 审计纪律：对比实验一律用官方仓实测参数量，论文自报数只作参考——这条写进论文的实验设置小节本身就是加分项；(3) 机理小节：把"小模型=受约束线性映射"的归因借来解释自家轻量方案为什么有效。
- **Kaggle-竞赛**（reuse_cost 中）：算力受限/推理时限的时序赛题上，按频率截断或周期折叠约束设计线性轻量层当快速基线或 ensemble 成员；跑得快意味着同一时限内能多轮交叉验证。
