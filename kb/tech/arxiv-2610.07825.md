# Forecast Accuracy Is Not Trading Profit：预测精度与交易赚钱是两个排行榜

> 来源：https://arxiv.org/abs/2610.07825 （v1 2026-10-06，Jonathan Chang/Zimeng Lyu；2026-10-29 经 arXiv API 实抓摘要）。本卡内容出自本次抓取的摘要，未读 PDF 全文。

## 是什么

把**预测精度榜**与**下游决策收益榜**并排评给同一批模型的对照研究。设定：股票收益预测，比较线性、固定递归、transformer、mixing 类架构，以及神经进化架构搜索出的递归网络；全部模型在合并面板上训练（一个网络服务整个股票域）；评估既看预测精度、也看日频多空策略的净收益。四个中盘组合、三个交易年的结果是：进化网络**两个榜都第一**，而**精度第二的模型在形成仓位、计入成本后亏钱**；优势与视界匹配相关——进化网络的 rank IC 从 1 天到 10 天评分视界上升，而 300 参数以上的所有模型都下降。效率上也是极端案例：16 分钟 CPU 搜索得到 66 权重网络，树莓派 Zero 上单次预测 10.8μs，对照 817,153 参数、需 GPU 训练的 transformer 基线。

## 解决什么问题

时序预测模型普遍按逐点误差比较，而逐点误差把预测与"预测为之服务的决策"割裂开——精度低一点不必然决策差，精度高一点不必然赚钱。本文给出一个干净的反例：两个排行榜可以给出几乎相反的排序。

## 相比前方法优势

- 双口径对照设计本身就是贡献：同一批模型、同一面板、同时报精度与净收益，"第二准=亏钱"是口径错位的最强证词；
- 把"为什么小网络赢"归因到可检验的机制：视界匹配（rank IC 随评分视界结构化变化、大模型全降），而非笼统的"小数据大模型过拟合"；
- 效率数字彻底：66 权重、16 分钟 CPU 搜索、10.8μs 推理——为"轻模型够用"提供了量级证据；
- 池化面板设定（一个网络跨整个股票域）避免了逐股过拟合的老坑，实验口径干净。

## 局限（如实标注）

- 无官方代码，神经进化的搜索空间/适应度细节需读全文才能复现；
- 仅覆盖中盘股、三个交易年、日频多空一种策略，"精度榜与收益榜背离"的普适性未证；样本期外的稳定性（换个年份排行是否翻转）摘要未报；
- 未含交易成本敏感性分析（成本假设变化是否改变排序）——需读全文；
- 结论域是"预测→交易决策"链，迁移到其他决策链（调度/补货）时需自建对应决策指标，不能照抄。

## 如何用于比赛（比赛映射展开）

- **数模-预测与评估**（reuse_cost 中）：凡"预测+据此决策"结构（库存调度、电力调度、投资组合）的赛题，交付双口径表——官方评分指标 + 决策层指标（成本/收益/违约率）各一列，若排序不一致就明说并以决策口径定夺模型：这一步是免费的，却直接封住"你们的模型精度不如 XX"类评审质疑。
- **Kaggle-竞赛**（reuse_cost 中）：metric 与叙事错位的赛道（评分用逐点误差、故事讲业务收益）照搬其双榜评估；"第二准亏钱"案例可直接写进 solution write-up 的 metric 分析段；轻量进化 RNN 路线适合算力受限的分站赛与设备端部署要求。
