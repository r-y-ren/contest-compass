# iRAG：知识库从一张白纸开始长——判例积累式的人机协同决策支持

> 来源：https://arxiv.org/abs/2610.12666 （v1 提交 2026-10-08，Federico Mazzoni/Andrea Failla；abs 页无 Comments、无代码/项目链接，2026-10-13 实抓）。本卡内容出自本次抓取的摘要页，未读 PDF 全文。

## 是什么

iRAG 把 RAG 与混合决策（Hybrid Decision-Making）结合做**人在回路（human-in-the-loop）决策支持**，针对知识库初始为空的场景：系统把专家的每一次决策**存成可检索的判例**，知识库由此逐步生长。系统的行为分三级递进：**静默旁观**（只记录）→ **有据反驳**（用既往判例支撑或质疑当前提案）→ **自主处理 + 弃权**（自行决定，置信不足时明确弃权交还人）。实验对照独立基线：无检索衰减时在 10% 漂移下终判误差打平、40% 漂移下全配置降低；而开启检索衰减虽改善已变化知识的处理、却推高稳定知识上的误差——**稳定性-可塑性权衡**，非普遍优势。

## 解决什么问题

常规 RAG 依赖预先建好的静态知识库，冷启动要一次性标注/整理语料。iRAG 把知识库变成"决策的副产品"：专家干活的同时库就在长，系统对人的依赖随判例积累而**按阶梯下降**，且每一步放权都有弃权兜底。

## 相比前方法优势

- **冷启动即用**：KB 为空也能上线（旁观模式），无需先攒语料；
- **自主度是显式架构**：三级阶梯让"什么时候信机器"成为工作流设计而非模型内部黑箱；人审是内建 provision，不是事后补丁；
- **权衡被如实量化**：检索衰减的增益与代价同时报告（改的知识变好、稳的知识变差）——没有把 trick 包装成普适改进；
- **可解释的判定链**：反驳与自主处理都引用既往判例，每条建议可溯源到"历史上类似决策怎么做"。

## 局限（如实标注）

- **无代码**：abs 页无链接，两人团队、自建评测——复现须从零搭整套系统；
- 评测为作者自设的漂移场景（10%/40% 漂移档位），无公开基准、无第三方对照；
- **真人可用性未验证**：摘要自述"usability with real human users remains to be evaluated"——人在回路的核心环节恰恰没有人的实验；
- 判例表示、相似度度量、弃权阈值等关键设计细节摘要未展开；
- v1 预印本无 venue，数字作者自报。

## 如何用于比赛（比赛映射展开）

- **双创-文书与申报**（reuse_cost 中）：任何"AI 辅助专业决策"类项目（法务助手、申报预审、信贷辅助）直接套其架构：专家每次人工裁决入判例库 → 系统先旁观后反驳再有限自主 → 低置信弃权。申报叙事上同时覆盖"越用越准"（判例生长）与"安全可控"（弃权阶梯）两点，且不需要冷启动数据集——特别适合没有历史数据积累的初创场景。
- **黑客松-数据与算法**（reuse_cost 中）：做决策支持类题目时，"判例引用链 + 弃权"是相对其他队伍"纯 RAG 问答"的机制级差异化：答案带"依据第 N 次类似裁决"，不确定时明说并转人工——演示效果与可信度双收。

**族内定位**：库内 30+ RAG 卡集中在检索质量/索引优化/攻击防御；本卡占"知识库生长机制 + 人机放权架构"位，与检索质量线正交——判定标准是"库怎么长、权怎么放"，不是"检索得准不准"。
