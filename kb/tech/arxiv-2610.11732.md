# MemTrial：市场 beta 混进经验信用——把记忆放上被告席

> 来源：https://arxiv.org/abs/2610.11732 （v2，2026-10-08，摘要经 arXiv API 实抓，2026-11-07）。本卡内容出自本次抓取的摘要，未读 PDF 全文。

## 是什么

诊断并修复"带经验的 LLM 投资组合 agent"的信用分配缺陷。问题：agent 把每条经验的信用记在"用了它的决策的结局"上，但市场里同日所有决策共享行情涨跌——信用追踪的是市场而非经验本身，导致这类 agent 常**跑不赢等权 1/N**。方案叫 **MemTrial**（把记忆放上审判席）：同一决策分别带/不带某条经验各草拟版本，同场面对同一行情，结局差分中共同项相消、剩下的即该经验的净贡献；每条决策用**分数阶因子设计**草拟 8 个经验组合，每条经验的信用记为差分均值的 **Banzhaf 值**；再以**分层贝叶斯**跨日期、跨相似经验池化降噪，且经验值须先在未见日期上证明有预测力才启用，否则锚定保守参考（如 1/N）。4 基准、15 方法对照：在带经验质量 ground truth 的半合成基准上 15 方法最佳；经验失效时损失有界——最多落后 1/N 约 **2.2%**。

## 解决什么问题

经验记忆的归因污染：outcome credit 里混着环境共同项（市场 beta），agent 学到"哪天行情好"而非"哪条经验好"。这在一切"共享环境下批决策"的记忆系统里普遍存在，不只金融。

## 相比前方法优势

- **差分设计消混杂**：带/不带同场对照，市场项在差分中相消——因果归因的黄金标准搬进 agent 记忆；
- **统计纪律完整**：分数阶因子设计控制草稿组合数（8 而非 2^k）、Banzhaf 值给 coalition 公平分配、分层贝叶斯池化压采样噪声、"先验证后启用"防止过拟历史——四层防线环环有出处；
- **下界可证**：失效时锚定 1/N、最多落后约 2.2%——记忆系统的下行风险第一次被显式约束；
- **评测有 ground truth**：半合成基准带经验质量真值，"信用分配对了没有"可验证而非自说自话。

## 局限（如实标注）

- 每决策 8 次草稿 = 推理成本翻 8 倍量级，摘要未给 token/时延开销与降本变体；
- 差分消的是**线性共同项**：非线性混杂（市场与经验的交互项）仍可能漏进信用；
- "相似经验"的相似度定义与池化粒度需读全文；实验限于组合管理域，其他决策域外推未证；
- 无代码释出（本轮实抓未见仓库），按 paper 处理。

## 如何用于比赛（比赛映射展开）

- **数模-数据分析与决策**（reuse_cost 中）：把"对照草稿差分"抽象成通用净效应估计器用于赛题：评估某因素净贡献时构造带/不带该因素的双版本同场对比；其"先在 held-out 上验证、不过就回退保守参考"的启用门是稳健性章节的现成素材。
- **黑客松-数据与算法**（reuse_cost 中）：交易/投资 agent 赛的合规设计模板——先证自己的记忆机制跑赢 1/N 再谈收益；其 15 方法对照表可直接作为 baseline 清单，"最多落后 1/N 2.2%"的下界话术适合答辩。

**族内定位**：库内记忆治理家族已有"准入/呈现两道闸门"（arxiv-2610.11188）、Mem++（组织级记忆结构）、Dynamics-memory（值动力学记忆层）——本卡占"**经验信用分配**"位：前三张管"记什么/怎么呈现"，本卡管"记了之后信几分"；与数模线的 Training on the Future（防泄漏）同属"决策记忆的统计卫生"叙事，可并引。
