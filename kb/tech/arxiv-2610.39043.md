# 模块化贝叶斯基础模型：让"选哪个专家"这件事自带不确定性

> 来源：https://arxiv.org/abs/2610.39043 （v1 2026-10-28，摘要经 arXiv API 实抓 2026-11-10）。本卡内容出自本次实抓摘要，未读 PDF 全文；GitHub repo search（2026-11-10）未见官方实现。

## 是什么

面向工业时序的模块化基础模型框架：不依赖单一 TSFM 表示所有工况，而是维护一组**奇异贝叶斯神经网络（SBNN）紧凑编码器**专家（在不同数据集上分别训练，可随需扩容），新样本由**认知不确定性引导的免标签路由**选择专家处理。三点实测（官方口径）：所选 rank 上比确定性对应物省 **63.8% 存储**；七个外来数据集上，不确定性路由的预测 MSE 与距离路由相当，而平均 ECE 从 0.086 降至 0.072、NLL 从 0.907 降至 0.836、PICP90 从 82.28% 升至 89.03%；另含与完整模型家族对比的 SBNN pipeline 评估。

## 解决什么问题

工业系统持续产生采样频率、尺度、动态、工况各异的时序，单一基础模型表示不了所有 regime，而为每次漂移重训大模型又贵。模块化方案（专家池 + 路由）是出路，但路由通常靠特征距离，既不能免标签地可靠选出专家，也没有"这数据不属于任何已知专家"的警报——把编码器做成贝叶斯的，认知不确定性就同时承担路由信号与 OOD 检测两个职责。

## 相比前方法优势

- **一个信号两个用途**：认知不确定性既是路由依据又是 OOD 报警器，不用额外训练判别器；
- **免标签**：路由不需要目标域标签，跨数据集部署（新客户新产线）无需先采集标注；
- **紧凑**：SBNN 编码器省 63.8% 存储，专家池扩容的存储成本被压低；
- **校准实测改善**：不只是"能用"，不确定性质量（ECE/NLL/PICP90）有逐项数字。

## 局限（如实标注）

- 未读 PDF 全文：SBNN 训练细节（变分推断形式、先验设置）、路由阈值敏感性、与 SOTA 单模型 TSFM 的精度对比表以摘要口径为准；
- 无官方开源实现（GitHub repo search 2026-11-10 未见），SBNN pipeline 从零自建成本高，reproducibility 定为 low；
- 实验规模（七数据集）偏工业场景，样本量与域覆盖有限；贝叶斯编码器的推理开销较确定性版本的代价未在摘要中量化。

## 如何用于比赛（比赛映射展开）

- **数模-预测与评估**（reuse_cost 高）：工况漂移/多源数据题（多机组、多站点、多产线）的建模选项与论文叙事：per-regime 专家池 + 不确定性路由的架构图可直接迁移，路由置信度还能产出"新工况警报"分析小节；无开源实现意味着只能按论文思路自建简化版（确定性编码器 + 简单不确定性估计近似），作为方法创新点的成本可控。
- **Kaggle-竞赛**（reuse_cost 高）：多店/多资产赛道把"专家池怎么路由"当成差异化实验点——uncertainty vs distance 路由的对照即一个可写进解决方案贴的创新叙事，MSE 不劣而校准更优的结论可复制为自证实验。
