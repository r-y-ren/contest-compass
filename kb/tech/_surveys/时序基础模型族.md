## 选型结论

### TSFM 押注前体检流程（8-28 版五步骨架保留，第 2 步升级为四轴证据链）

族内 14 卡收敛于同一立场：**TSFM 是任务依赖的部署选项，默认轻量基线打底、按题型定点入场，押注前必须体检**。与 8-28 三卡时代相比，体检从"单一协议"升级为**四轴证据链**，每轴都有对头部模型（Chronos-2/TimesFM/Moirai/Toto）的失效实证：

1. **任务形态分流（2608.22968 + 2609.39386 + 2608.24033 + 2610.00978 先验）**：退化预测/异常检测类题 → 默认轻量方案（TCN-AE/OCSVM 级），TSFM 不进主方案（异常检测如走 TSFM，走 00978 表示路由而非裸打分）；"何时发生"型稀疏事件题 → **禁用点预测直读**，改冻结骨干+线性探针或分位数平均（39386：点预测较免训练基线至多 +0.031）；时序分类且标签稀缺 → 试 ChorusTIC 零训练基线；规则采样预测题 → 进第 3 步。
2. **四轴体检（每轴半天内可完成，全部无需训练）**：
   - **域熟悉度**（2609.10357）：赛题数据域是否在候选 TSFM 预训练语料里？做"近域/远域"两组自评对照——Wikipedia 域 28% MASE 优势=语料红利的教训直接引用；
   - **基础逻辑**（2610.02058）：单调/周期/先行指标合成序列 10 分钟体检，命中盲点（如协变量先行指标被欠用）→ 协变量显式对齐领先期后自建特征层；
   - **模式保真**（2608.24303）：参数化合成生成器单因子干预，命中失效先验（持续性高估/体制转换突变失效）→ 该模式所在赛题慎押或预置兜底；
   - **成本计量**（2608.22968）：时延/峰值 VRAM/state-dict 与精度并列进对比表（AdaCast 类重适配方案尤须先掂量：21.6 GB 峰值显存）。
3. **基线对照（2608.22968 协议 + 24033 + 39386 四件套）**：out-of-fold + 配对 bootstrap CI 的轻量基线对照；分类题加 ChorusTIC 零训练基线（先处理无 license 风险）；稀疏事件题按"点预测/探针/GBDT/随机对照"四件套并排报告。TSFM 只有显著优于轻量基线才进主方案。
4. **押注判据（三条件同时成立才押）**：(a) 四轴体检未命中失效先验；(b) 成本计量可承受；(c) OOF+CI 显著优于轻量基线。任一不成立 → TSFM 退出主方案，降级为集成成员/残差建模/表示底座（2610.00978/2609.21381/2609.39386 探针三条"当底座不当预测器"的退路均已实证）。

### 按赛题形态选型

- **规则采样预测题（负荷/销量/电价）**：零样本底座按当前可下载梯队 **Chronos-2 / TimesFM-3**（2609.39386/2610.11734 卡口径）+ Tabby 作概率输出候补；微调时 **ScaleIn 一行改动作默认项**（2610.07324）；域适配默认 static LoRA（2608.11359 脉络，时序预测族）、异构序列分解显示部分区域恶化再考虑 AdaCast 式逐输入适配（2610.12240）；Timer-M1 权重放出后多变量+协变量题型优先纳入对比（2610.11734 触发器）。
- **不规则采样题（医疗/穿戴/稀疏传感）**：生理信号域直接用 SOTER 权重零样本试水（2609.16804，JSONL+归一化+官方示例）；非生理域取 2609.22836 的 time-aware patching+time-bias attention 架构模式自建，对照"插值+规则模型"基线论证失真来源。
- **工程仿真代理题（水文/管网/环境）**：KG-Chronos-2 三段式配方（2609.21381）：公开 TSFM 冻结底预测+工况相似检索+残差头，替代从头训网络拟合仿真；写作以"仿真加速器"定位、主动声明不代理现实。
- **分类/异常检测题**：分类走 24033 免训练 ICL；异常检测走 2610.00978 表示路由（免目标域标签），都不行再回轻量专用模型。
- **概率/区间题**：Tabby 分位数输出或 2609.13345（概率预测族外综述）按图选路线——其"无单一 UQ 范式全面占优"结论与本族 39386"分位数平均替代取中位"互洽。

### 组合打法

数模论文"模型选型论证"章节全家桶 = **四轴体检**（10357 域对照表 + 02058 原语体检 + 24303 模式干预 + 22968 成本计量）+ **基线对照三件套**（OOF+CI+成本并列）+ **ScaleIn/协变量三角色两个训练侧消融点**。合计成本约等于两三次推理 API 扫描 + 几十行合成器代码，是赛场可承受的最低体检配置，且每一轴都有论文级失效案例可引。

### 不推荐清单

- 不推荐把 TSFM 当轻量拟合模型的默认替代（2608.22968：退化/异常任务轻量全面占优且时延/VRAM/state-dict 全维度更省）。
- 不推荐用 TSFM 点预测直读"何时发生"型目标（2609.39386：近乎基线无异甚至更差）——先探针/分位数平均。
- 不推荐只报基准总分引用体检类卡结论（须保留"任务依赖"限定防断章；2609.10357 的域对照表说明"榜分"本身可能是语料红利）。
- 不推荐微调当免费午餐（2610.02058：Chronos-2 微调改善特定任务却恶化其他基础模式）——微调前后各跑一遍原语体检。
- 不推荐引用无码无权重的本体/适配卡作"已验证方法"（2610.11734 Timer-M1 / 2610.12240 AdaCast / 2609.22836 / 2609.39386 / 2610.02058 / 2610.07324 / 2609.21381 / 2608.24303 / 2608.22968 均 runnable=false）：取协议/蓝图/选型先验，不取"复现背书"。
- 不推荐在 license 缺失状态下把 2608.24033 checkpoints 进作品分发链路；不推荐依赖 2610.00978 匿名仓长期可用（落地前快照）。
- 不推荐以"合成体检通过"替代真实数据 out-of-fold 验证（2608.24303 生态效度局限）。
