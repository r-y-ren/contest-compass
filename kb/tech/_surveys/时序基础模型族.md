## 选型结论

### TSFM 押注前体检流程（8-28 版五步骨架保留，第 2 步四轴证据链——本轮协变量轴升级为三卡证据链）

族内 27 卡收敛于同一立场：**TSFM 是任务依赖的部署选项，默认轻量基线打底、按题型定点入场，押注前必须体检**。与 10-11 版相比，体检证据链的最大变化是**协变量维度从单点警示升级为三卡专属证据链**（编码怎么选 / 质量怎么分层 / 反事实怎么诊断）：

1. **任务形态分流（2608.22968 + 2609.39386 + 2608.24033 + 2610.00978 + 2610.06180 先验）**：退化预测/异常检测类题 → 默认轻量方案（TCN-AE/OCSVM 级），TSFM 不进主方案（异常检测如走 TSFM：多工况异质面板走 00978 表示路由、判定依赖工况正常参考时取 06180 反事实监督思路，两者机理不同可对照）；"何时发生"型稀疏事件题 → **禁用点预测直读**，改冻结骨干+线性探针或分位数平均（39386：点预测较免训练基线至多 +0.031）；时序分类且标签稀缺 → 试 ChorusTIC 零训练基线；规则采样预测题 → 进第 3 步。
2. **四轴体检（每轴半天内可完成，全部无需训练）**：
   - **域熟悉度**（2609.10357）：赛题数据域是否在候选 TSFM 预训练语料里？做"近域/远域"两组自评对照——Wikipedia 域 28% MASE 优势=语料红利的教训直接引用；
   - **基础逻辑与协变量**（2610.02058 + 2610.13676 + 2610.07232 + 2610.08118）：单调/周期/先行指标合成序列 10 分钟体检；日历编码当免费超参在验证段自扫（不可照抄他人配置）；未来协变量先做质量分层——官方统计/日程表类可靠源直接喂，自预测类噪声源按 07232 结论把 TimesNet 级鲁棒模型纳入对照；赛题含干预/情景分析问法 → 按 08118 先验：经典系统辨识做因果骨架，TSFM 协变量回答只当展示性基线（坚持用则 context dither + 合成强迫系统微调修复，并用成对反事实输入自证无衰减）；
   - **模式保真**（2608.24303）：参数化合成生成器单因子干预，命中失效先验（持续性高估/体制转换突变失效）→ 该模式所在赛题慎押或预置兜底；
   - **成本计量**（2608.22968 + 2610.05269）：时延/峰值 VRAM/state-dict 与精度并列进对比表；UniScale 缩放律给"再堆历史/换大模型值不值"的量化论证（容量收益随历史变长而增长、上下文收益饱和）；AdaCast 类重适配方案尤须先掂量（21.6 GB 峰值显存）。
3. **基线对照（2608.22968 协议 + 24033 + 39386 四件套）**：out-of-fold + 配对 bootstrap CI 的轻量基线对照；分类题加 ChorusTIC 零训练基线（先处理无 license 风险）；稀疏事件题按"点预测/探针/GBDT/随机对照"四件套并排报告。TSFM 只有显著优于轻量基线才进主方案。
4. **押注判据（三条件同时成立才押）**：(a) 四轴体检未命中失效先验；(b) 成本计量可承受；(c) OOF+CI 显著优于轻量基线。任一不成立 → TSFM 退出主方案，降级为集成成员/残差建模/表示底座（2610.00978/2609.21381/2609.39386 探针/2610.04827 偏差修正四条"当底座不当预测器"的退路均已实证或给出配方）。

### 按赛题形态选型

- **规则采样预测题（负荷/销量/电价）**：零样本底座按当前可下载梯队 **Chronos-2（41956，多变量+协变量首选）/ Timestral（37585，三榜 SOTA 概率输出）/ TimesFM-3**，快档加 Yug（yug，CPU 级出区间基线，无论文自测先行）；协变量可靠 → Chronos-2（07232），噪声协变量 → TimesNet 级鲁棒模型进对照；微调时 **ScaleIn 一行改动作默认项**（2610.07324）、**金融题加 VCA 波动聚集惩罚**（2609.37715）；日历编码按 13676 自扫；域适配默认 static LoRA（2608.11359 脉络，时序预测族）、异构序列分解显示部分区域恶化再考虑 AdaCast 式逐输入适配（2610.12240）；Timer-M1 权重放出后多变量+协变量题型优先纳入对比（2610.11734 触发器）。
- **零样本集成的合并层**：多个 TSFM 成员 → **QUAL 对齐后合并**（2610.41100，免标签、混弱模型稳健）；单模型输出 → 分位数平均（2609.39386 改法）。
- **不规则采样题（医疗/穿戴/稀疏传感）**：生理信号域直接用 SOTER 权重零样本试水（2609.16804，JSONL+归一化+官方示例）；非生理域取 QiYao-I（2610.06936）的流形时间编码+按需变量交互或 2609.22836 的 time-aware patching+time-bias attention 架构模式自建，对照"插值+规则模型"基线论证失真来源。
- **工程仿真代理题（水文/管网/环境）**：KG-Chronos-2 三段式配方（2609.21381）：公开 TSFM 冻结底预测+工况相似检索+残差头，替代从头训网络拟合仿真；写作以"仿真加速器"定位、主动声明不代理现实。
- **分类/异常检测题**：分类走 24033 免训练 ICL；异常检测走 2610.00978 表示路由（免目标域标签）或 2610.06180 参考条件化思路（工况相对判定），都不行再回轻量专用模型。
- **含文本/事件上下文的预测题**：Pythia（2610.05240）作架构对标——可实现降配版为 LLM 提取结构化事件特征+协变量进预测模型，引用注明预印本自报与无代码现状。
- **概率/区间题**：Timestral/Tabby 分位数输出 + QUAL 合并层；概率生成式路线（Koopman 一步生成 KGO 2611.04760、流匹配 MercerFlow 2610.06039）按首词判例在时序预测族，按图跨族引用——其"无单一 UQ 范式全面占优"结论与本族 39386"分位数平均替代取中位"互洽。

### 组合打法

数模论文"模型选型论证"章节全家桶 = **四轴体检**（10357 域对照表 + 02058 原语体检 + 13676 编码自扫/07232 协变量分层/08118 反事实自证 + 24303 模式干预 + 22968/05269 成本与缩放律）+ **基线对照三件套**（OOF+CI+成本并列）+ **ScaleIn/VCA/日历编码三个白拿增益消融点**。合计成本约等于两三次推理 API 扫描 + 几十行合成器/后处理代码，是赛场可承受的最低体检配置，且每一轴都有论文级失效案例可引。

### 不推荐清单

- 不推荐把 TSFM 当轻量拟合模型的默认替代（2608.22968：退化/异常任务轻量全面占优且时延/VRAM/state-dict 全维度更省）。
- 不推荐用 TSFM 点预测直读"何时发生"型目标（2609.39386：近乎基线无异甚至更差）——先探针/分位数平均。
- 不推荐只报基准总分引用体检类卡结论（须保留"任务依赖"限定防断章；2609.10357 的域对照表说明"榜分"本身可能是语料红利）。
- 不推荐微调当免费午餐（2610.02058：Chronos-2 微调改善特定任务却恶化其他基础模式）——微调前后各跑一遍原语体检。
- **不推荐把 TSFM 协变量接口当 what-if 引擎直接做情景推演**（2610.08118：响应衰减至真值 0.33-0.80、TimesFM-2.5/TabPFN-TS 无记忆）——经典系统辨识兜底；坚持用则修复两招+反事实输入对自证。
- **不推荐默认把未来协变量（尤其自预测的噪声源）喂进 Chronos-2 而不做质量分层**（2610.07232：噪声下优势反转、TimesNet 更稳）——先做敏感性分析再定选型。
- **不推荐照抄他人的日历编码配置**（2610.13676：有效性与利用率跨模型不可迁移）——按所用模型在验证段自扫。
- **不推荐把 Yug（gh-birla-ai-labs_yug）当已验证模型引用**：无论文无公开基准，能力未知——自跑小样本对照后再决定进不进主方案。
