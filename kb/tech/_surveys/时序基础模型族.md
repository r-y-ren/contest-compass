## 选型结论（TSFM 押注前的低成本体检流程）

七卡收敛于同一立场：**TSFM 是任务依赖的部署选项，押注前必须体检**（22968 给"何时值"的先验，24303/08118/07232/06453 给四条失效轴的诊断协议，24033 给"分类任务免费试"的选项，16804 给"域错配时换域专用架构"的出路）。体检流程五步，全部无需训练：

1. **任务形态分流（22968 先验 + 新卡补充）**：退化预测/异常检测类题 → 默认轻量方案（TCN-AE/OCSVM 级），TSFM 不进主方案（确需 TSFM 时走 06453 适配路线）；预测残差诊断类 → TSFM 可试；时序分类且标签稀缺 → 试 ChorusTIC（24033）；负荷/能耗类 → 先评未来协变量质量（07232 先验：可信 → Chronos-2 零样本强基线，噪声大 → TimesNet 兜底）；不规则采样生理信号 → 参 16804 域专用配方；情景/what-if 问法 → 进第 2 步做响应保真诊断。
2. **模式与响应双体检（24303 协议 + 08118 协议）**：列出赛题数据的关键模式清单（趋势/谐波/体制转换/能量释放等），对每个模式构造参数化合成生成器，对候选 TSFM 做单因子干预测模式保真度（24303；命中持续性高估/体制转换失效先验 → 该模式慎押或预置兜底）；若赛题含干预/情景问法，加做 08118 响应保真对照——同上下文拟合经典系统辨识 vs TSFM 协变量接口比较增益，命中衰减先验 → 情景章以经典辨识兜底。
3. **成本计量（22968 协议）**：候选模型跑时延/峰值 VRAM/state-dict 尺寸，与精度并列进对比表——赛场算力与演示时延约束下的硬指标。
4. **基线对照（22968 协议 + 24033）**：out-of-fold + 配对 bootstrap CI 的轻量基线对照；分类题加跑 ChorusTIC 零训练基线（动手前先处理其无 license 风险）；TSFM 只有显著优于轻量基线才进主方案，否则降级为集成成员/残差建模，或仅作对照章节素材。
5. **押注判据（三条件同时成立才押 + 两类附加门）**：(a) 体检未命中任一失效轴先验；(b) 成本计量可承受；(c) OOF+CI 显著优于轻量基线。任一不成立 → TSFM 退出主方案。附加门一（异常检测题）：裸误差分数禁用，须叠加 06453 NCL 适配并复测区分度后再评；附加门二（情景分析题）：TSFM 协变量接口不裸用，先过 08118 对照。

**组合打法**：数模论文的"模型选型论证"章节 = 24303 模式体检 + 08118 响应保真对照 + 07232 协变量质量梯度 + 22968 三件套协议（精度/统计/成本并列）+ 24033 防泄漏 ICL 评测（分类题）+ 06453 适配层（异常检测确需 TSFM 时）。合计成本约等于两三次推理 API 扫描 + 一次自建合成器 + 一次最小二乘辨识，仍是赛场可承受的最低体检配置。
