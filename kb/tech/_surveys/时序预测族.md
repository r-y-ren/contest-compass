## 选型结论

以下结论仅由上述 42 张库内卡片支撑，按赛题形态给出。

### 开局纪律（全赛题通用第一层）

- **基线纪律打底**（gh-dreamers-laboratory_timeseries-atlas）：任何预测问第一层强制 DLinear/经典统计（其自包含实现一分钟出数），打不过基线就不上重模型——"打过 DLinear 了吗"是队内 checklist 也是答辩底气。
- **工程底座**（arxiv-2609.39741 Nixtlaverse）：开局用一条管线铺满统计+ML+神经三家族 baseline 矩阵与滚动起源评估，层级调和直解"分项加总≠总量"；M5 规模画像指导"多少序列以上值得上神经模型"。
- **是否引入外部变量的事前诊断**（arxiv-2608.25128）：δ=0 或末值捷径主导时任何融合机制都无增益，把精力还给特征工程与残差修正。

### 按赛题形态选型

- **滚动/在线评测与非平稳部署题** → I 组按角色分工：评测纪律用免泄漏验证片规程（2609.01126，成本最低、收益最确定）；重训调度用 PILOT 触发器（2609.39789，写"系统运维方案"章节）；模型侧在线适配默认轻量（01126 的头部适应），要基座泛化再上 CoSPOT（2609.02093）；LLM 参与时按"控制器（2609.23257 CTRL）/自进化记忆（2609.32689 FASE）"选型——全部先过"赛期有没有 LLM API、有没有逐期反馈流"的可行性闸门。
- **事件/文本/图像增强题** → 结构化事件字段 ReasonCast（2608.15291）+残差事件修正 CEDAR（2608.25871）叠用；题目附新闻/报告文本 → SCENARIODIFF（2608.17164，先快照匿名仓）或 MIDAPN 统一主干（2610.11924，文本可预对齐时）；带云图的光伏/气象题 → SolCloudLLM 叙事+few-shot 协议（2609.11135）；变量含义可描述 → SAGE 语义注入降配版（2608.26829）；题问"事件影响多大" → EventTime（2608.19447）。
- **概率区间/CRPS/分位数计分** → 按算力与数据质量分档：CPU 级轻量主力 DecoVAE（2608.20052）/对比正则叠加 CLaST（2608.20025）；算力充足且有缺测污染时扩散路线 DynG-Diff（2609.02068，变量级动态引导）；输出端一律再套 SPACE 共形椭球（2608.17333）把"经验分位"升级为"有限样本覆盖率保证"。
- **检索增强** → 修正已训基座选 RATL 残差记忆（2609.03937，注意基座专用）；LLM 提示选样选 CASP-LLM 覆盖正则（2609.22977，先判场景：高噪声多模式数据不增益）；相似日检索选未来监督重排（2608.23221，必须朴素锚定/相似日/重排三方 A/B）。
- **冷启动/小样本** → 三条路对照：TMAML 元学习改训练目标（2610.04547）、MetaCaster LLM 合成增广（2608.23473）、TSFM 零样本（跨族见时序基础模型族 survey）；无图像数据也可借 ICI-Time（2608.23855）做零训练对照。无预训练语料可依时元学习是第三条路。
- **不规则时间戳采样** → D 组配对：DNBNet（2608.17284，预测端，官方代码可 clone）+ CSE 指标（2608.17293，评估端一行级改写）。
- **能源题** → Chronos-2 零样本+MSMI 协变量（2608.11359）+ TabPFN-TS 起点配置（2608.20024）双基线；TSFM 微调侧配方（ScaleIn 等）跨族取用；多市场排序加 CalibRank 诊断（2608.14106）。
- **留存/churn 类表格时序** → PPDL 三段式（2609.13789）：Weibull 参数化趋势+残差网络+趋势惩罚损失，外推有形状约束兜底。
- **评审重视可解释性的题** → 建模层 Fuzzy-MoE（2608.20761）、表征层 ConceptTS（2608.21277）、事后层 NVExplain（2608.25080）按需选层。
- **算力受限/宽变量** → AsyTO（2608.16098）自实现作主力，先与 DLinear/TiDE 同台对比；通用提速 topping 加 AdaRDiff（2608.28134）。

### 组合打法

1. **滚动预测题"部署线全家桶"**（2026-10-13 新增）：免泄漏验证片规程打底（2609.01126）→ PILOT 触发器写运维章节（2609.39789）→ RideBench 协议做赛前演练与场景分情景评测（2610.11164）→ 需要在线适配时 CoSPOT/头部适应对照静态基线（2609.02093+2609.01126）→ LLM 类（2609.23257/2609.32689）仅在 API 可用且轻量基线打不过时入场。逻辑链：每步都有库内卡片背书，且整条线回应"模型部署后如何维持精度"这一多数答卷的空白。
2. **事件驱动销量题全家桶**：2608.25128 事前诊断确认事件信息增量 → DLinear 级轻量基线打底（2608.18675 + atlas）→ ReasonCast 结构化事件特征+选择性门控 → CEDAR 式残差事件修正层专攻突变日 → 评估按 LiveHouse-TS（2608.17299）分时间窗滚动 + Multiplicity 轨迹散差图（2610.09994）收尾稳健性章节。
3. **不规则采样题"预测+评估+区间"三件套**：DNBNet 主力（17284）+ CSE/MSE 双排名并列报告（17293）+ 题面要求区间时叠 SPACE 校准（17333）。
4. **多模态题按数据形态分流**：文本可预对齐 → MIDAPN 统一主干（2610.11924，可跑仓）；仅图像流 → SolCloudLLM 叙事+few-shot 协议（2609.11135）；变量可描述 → SAGE 降配（2608.26829）；都不可行 → 回退 ReasonCast 结构化事件字段。开工前先跑 2608.25128 两前置检查确认信息增量。

### 不推荐场景

- **规则均匀采样数据上强推"去偏"**：DNBNet 与 CSE 的收益集中在真不规则场景（两卡局限原话）——但 CSE 作为低成本评估自觉并列报告仍可保留。
- **纯点预测 MAE 计分的赛题押注概率建模**：DecoVAE/CLaST 的概率优势在点误差口径下打折。
- **稳定无事件序列上无差别堆文本/语义特征**：ReasonCast 实测无差别干预使稳定期 WMAPE 恶化 1.68pp——事件修正必须带门控。
- **高信噪比目标强套排序损失**：CalibRank 现象主体在弱可预测目标上演示；直优化相关性有幅度膨胀超一个量级的翻车风险。
- **δ≈0 或末值捷径主导时上多模态/外部变量**：2608.25128 分布无关不可能性结论，投入即浪费。
- **无 LLM API 预算或离线赛场强上 LLM 重管线**：CTRL（23257）、FASE（32689）、CoSPOT（02093）均依赖 LLM 推理；SCENARIODIFF（17164）栈重同理。
- **一次性预测任务（无滚动反馈）套 FASE 式自进化**：收益绑定反馈可累积，无反馈流则零收益空间（32689 卡局限原话）。
- **匿名通道数据用语义/图像叙事**：SAGE（26829）写不出变量描述、SolCloudLLM（11135）无图像流时此路不通。
- **非对齐文本硬上 MIDAPN 多模态路径**：官方对齐数据由 LLM 整理，非对齐文本的对齐成本自担（2610.11924 卡明示）；无 license 仓不进作品分发链路。
- **高噪声多模式数据（Electricity 类）硬上 CASP-LLM 覆盖正则**：论文自证该场景不增益（2609.22977 卡明示）。
- **3-4 天赛期内完整复刻无代码重系统**：CEDAR、MetaCaster、TRACE-CASH、SCENARIODIFF、SolCloudLLM、SAGE、RATL、FASE 全系统均属高成本，一律取最小可行版或降级实现。
