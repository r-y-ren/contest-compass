# 预测准 ≠ 效应估得对：基础模型的"世界模型"能力实测

> 来源：https://arxiv.org/abs/2611.15009 （v1 2026-11-11，摘要经 arXiv API 实抓）；伴随仓 https://github.com/DrSquare/FMTS_Workshop_Causal_Response 信号经 GitHub API 实查（2026-11-13）。本卡内容出自本次抓取的摘要与仓库元数据，未读 PDF 全文。

## 是什么

评测研究："时序基础模型能否从预测跃迁到世界建模（恢复因果响应）"。以零售场景为试验床：模型预测销量准，不代表它说得出"价格变了销量怎么响应"。评测对象覆盖已发布的表格基础模型、时序基础模型，以及一个专门为因果效应估计预训练的基础模型。三条发现：(1) **预测精度与价格效应估计精度脱钩**——真值已知的仿真数据和真实零售记录上均成立；(2) 对表格基础模型，**加上下文改进预测但不改进价格效应估计**；(3) 计量经济学的标准药方工具变量（IV），**只在特定供给形式下降效应误差；以原始 IV 形式供给时，混杂场景下所有模型的误差都变大**。

## 解决什么问题

"预测器当世界模型用"的隐性误用：社区默认 TSFM/表格 FM 在下游任务上是通用预测件，政策响应/干预效应这类"如果动 X，Y 会怎样"的问题也被顺手丢给它。本文给出该误用的系统证据与边界条件，让"预测技能"和"因果响应恢复"在评测层面分开记账。

## 相比前方法优势

- **双证据源**：真值已知的仿真 + 真实零售数据，结论不是单数据集巧合；
- **覆盖专门因果预训练模型**：连"为效应估计专门预训练的 FM"也在测列里，结论对"选对模型就能免灾"的侥幸心理也成立；
- **IV 供给形式的精细发现**：不是"IV 有效/无效"的粗结论，而是"什么形式有效、什么形式有害"——直接可操作的负结果；
- **伴随仓可跑**：评测协议有代码支撑。

## 局限（如实标注）

- 0 stars workshop 伴随仓（9 月推送，早于 arXiv 正式版），非正式发布件；
- 零售/价格效应单一场景族，其他干预类型（供给端、网络效应）未覆盖；
- 摘要未给效应误差的具体量化幅度（"脱钩"的散点口径）与各模型分项表；
- 结论是"当前 released 模型不行"，不代表下一代模型或专用微调后仍不行——时效性强。

## 如何用于比赛（比赛映射展开）

- **数模-预测与评估**（reuse_cost 低）：作为"方法论护栏"引用成本极低——凡是赛题要求"预测 + 政策建议/敏感性分析"，论文的效应分析章节若用 TSFM 直接外推政策响应即可被本文结论质疑；正确姿势是预测与效应分开建模，并把 IV 供给形式检查写进稳健性分析。三结论都可注明出处直接引用。
- **数模-数据分析与决策**（reuse_cost 低）：定价/补贴类决策题的选型依据：预测用 TSFM、效应估计走因果管线（DML/IV/实验设计），两条管线的结果在论文里分开呈现；"加上下文只帮预测不帮效应"提醒别把协变量工程的重心错放在效应模型上。

**族内定位**：库内"预测≠因果"意识已有先例——Training on the Future（arxiv-2610.12232）审的是测试时适应的因果泄漏（时间完整性），DDCI（arxiv-2610.26987）做区间校准。本卡占"**基础模型因果响应恢复评测**"位：审的不是预测器的时间纪律，而是"预测技能是否外推为效应估计技能"——与 Chronos-2（arxiv-2610.41956）、KGO（arxiv-2611.04760）等 TSFM 选型卡配套使用：选型卡告诉你哪个模型预测强，本卡告诉你预测强不等于效应准，效应题另走管线。
