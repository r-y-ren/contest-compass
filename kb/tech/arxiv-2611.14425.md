# 采样频率变了 TSFM 还稳吗：四模型压力测试与三个新指标

> 来源：https://arxiv.org/abs/2611.14425 （v1 2026-11-10，摘要经 arXiv API 实查；GitHub search 2026-11-13 实查无官方实现）。本卡内容出自本次抓取的摘要，未读 PDF 全文。

## 是什么

TSFM 的**采样频率不变性（SF-invariance）**定量压力测试。场景动机：传感器应用里采样频率随设备/工作模式（如省电模式）变化，理想 TSFM 应在 SF 变化下保持有效——前提是任务关键带宽仍在。被测对象：MOMENT、Chronos-2、Moirai-MoE、TimesFM 四个主流 TSFM。三个诊断维度各配一个新指标：嵌入漂移 **FSI**、预测退化 **FDI**、下游任务退化 **CDI**。作者自称首个把 SF 不变性置于 TSFM 评测核心的研究。三条刻画结论：SF 不变性取决于**信号原生采样率与任务所需带宽之间的余量**；模型选择能解释多少不变性；低 SF 下的性能损失有多少是信息丢失（而非模型能力缺陷）。总体重构：SF 不变性是 **(信号 × TSFM) 对**的可测属性，而非模型的普适性质。

## 解决什么问题

传感器数据进 TSFM 前的"要不要统一重采样"此前靠直觉：SF 变了就重采样，代价高且未必必要。本研究给出判据与量化工具——不变性跟带宽余量走、不跟 SF 数值走，"降采样"从禁忌变成有余量即可行的选项。

## 相比前方法优势

- **维度设计干净**：嵌入/预测/下游三层退化分开度量（FSI/FDI/CDI），能区分"表示动了但任务没事"与"任务真的掉了"；
- **带宽余量原则**：把"SF 鲁棒性"从模型单侧属性校正为 (信号×模型) 双侧属性——解释了为何同一模型忽稳忽不稳；
- **四个主流模型同面板**：选型结论直接可用（哪个模型对 SF 变化最不敏感），覆盖 Chronos-2/TimesFM 等库内常用选型件；
- **对损失归因**：能分离"信息带宽丢失"与"模型能力不足"，低 SF 结果不再被一刀切解读。

## 局限（如实标注）

- **无官方代码**：三指标的实现细节（嵌入对齐方式、退化窗口）需按论文复刻；
- 四模型面板之外的 TSFM（TiRex/Timestral 等库内其他选型件）未测，结论外推要谨慎；
- 摘要未给量化幅度（各模型 FSI/FDI/CDI 数值、临界余量阈值），"多少余量才安全"需读全文；
- 传感器应用族内测试，金融等非传感器域的 SF 变化场景未覆盖。

## 如何用于比赛（比赛映射展开）

- **数模-预测与评估**（reuse_cost 低）：赛题数据含多设备混合采样率（常见于环境/健康/工业数据）时，先按带宽余量原则判断统一重采样是否必要，再按模型敏感度结论选 TSFM；论文方法章节引用其三指标做稳健性诊断的设计模板。
- **Kaggle-竞赛**（reuse_cost 低）：传感器赛题的预处理决策：省掉不必要的重采样工序（省时间省算力），或在必须降采样时按"哪个模型 CDI 最小"选骨干；三个指标可写成赛题 pipeline 的自检步骤，答辩时是"我们量化过预处理决策"的加分点。

**族内定位**：库内 TSFM 选型/评测线已有 Chronos-2（2610.41956 选型卡）、TSFM 概率校准评测框架（2611.03592，校准维度）、日历特征编码系统研究（2610.13676，协变量编码维度）、MAPS（2610.33209，可预测性度量）。本卡占"**采样频率维度**"位：校准评测管"分布对不对"、协变量编码研究管"日历特征怎么喂"、本卡管"采样率变了还灵不灵"——评测维度互不重叠；传感器类赛题选型时与 Chronos-2/Timestral 选型卡并读。
