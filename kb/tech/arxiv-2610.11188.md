# 记忆治理两道闸门：什么能进上下文、进去后怎么说

> 来源：https://arxiv.org/abs/2610.11188 （arXiv abs 页 v1 2026-10-08，2026-10-16 实抓）。本卡内容出自本次抓取的摘要页，未读 PDF 全文。

## 是什么

对 LLM agent **持久记忆**的治理研究。作者把治理拆成两个独立决策——**准入**（召回的信息哪些进工作上下文）与**呈现**（准入的信息如何表述）——并提出两个推理时、免重训的准入设计：FC（factor-compiled，整条记忆评估）与 PS（permission-semantic，把条目分解为带类型的单元逐个裁决），均以确定性策略把裁决属性转成资格判定。

## 解决什么问题

持久记忆提升个性化的同时会诱发**谄媚（sycophancy）与跨域泄漏**：过去对话里的偏好、医疗或财务片段在无关任务中被不当召回并影响回答。要一套不动模型权重的闸门，决定"什么可以进上下文、以何种面目出现"。

## 相比前方法优势

- **决策解耦的分析框架**：准入与呈现分开裁，消融得以定位收益来源——收紧准入单独再降跨域失败 17.5 点（p=1.6e-4），而**呈现层的对照无一在多重比较校正后存活**——优先级结论明确；
- **确定性、可审计**：裁决属性→资格判定是确定性策略，免重训、可解释，企业场景友好；
- **统计纪律强**：四骨干开发套件 + 外部基准（4 任务×300 样本），合并失败率降 6.7/8.8 个百分点（p=2.7e-7 / 4.1e-12），PS 在匹配预算下经 Holm 校正后胜过随机与相关性选择；
- **如实报告负面**：两设计都会**增加个性化失败**，PS 未达预注册的改进与个性化保持标准——结论克制为"选择质量提供任务特定安全增益"。

## 局限（如实标注）

- **安全-个性化权衡未解决**：作者自陈"保留有益记忆使用仍悬而未决"——照搬会伤个性化体验；查询条件化门控基线无显著变化，说明朴素方案不够；
- 摘要页无代码链接，未找到开源实现（reproducibility 低）；裁决属性怎么来（谁打标）摘要未展开；
- v1 预印本在投 AAMAS 2027，未过同行评审。

## 如何用于比赛（比赛映射展开）

- **双创-文书与申报**（reuse_cost 中）：申报个性化助手/陪伴类产品时，"两道闸门"是现成的合规架构叙事：引用其泄漏数字与优先级结论（先准入后呈现），并如实写入"治理会牺牲部分个性化，我们如何补偿"——比空谈隐私安全更可信。
- **黑客松-数据与算法**（reuse_cost 中）：任何带长期记忆的 agent demo，加一层 FC/PS 式确定性准入即可现场演示"记忆泄漏 vs 治理后"对照——成本低、演示效果直观。

**族内定位**：库内 agent 记忆类卡偏"积累与复用"位（如经验沉淀/知识蒸馏类），本卡占"准入治理"位——是记忆管线的质检环节，与积累类卡互补而非竞争。
